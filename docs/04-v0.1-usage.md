# 04 · v0.1 体验版：安装、操作与排查

> 构建产物：`android/app/build/outputs/apk/debug/app-debug.apk`（44MB，含端侧模型 + ONNX Runtime）
> 一键脚本：`tools/push_to_quest.sh`（构建 → 安装 → 启动）

## 1. Quest 3 侧准备（只需做一次）

1. 手机装 **Meta Horizon** App，登录与头显相同的账号
2. 头显里：`设置 → 系统 → 开发者` → 打开 **开发者模式**（若没有该项，先在第 1 步的 App 里为设备开启）
3. 继续在 `设置 → 系统 → 开发者` → 打开 **USB 调试**
4. USB-C 数据线连到 Mac；头显里会弹出 **允许 USB 调试** → 勾选"始终允许" → 确定

验证连接：
```bash
adb devices -l     # 应看到你的头显，状态为 device
```

> 无线方式（可选）：`设置 → 系统 → 开发者 → 无线调试`，记下 IP，然后
> `./tools/push_to_quest.sh 192.168.1.23`

## 2. 构建 + 安装 + 启动

```bash
./tools/push_to_quest.sh            # USB 直连
./tools/push_to_quest.sh 192.168.1.23   # 无线调试
```

手动等价命令：
```bash
cd android && JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew assembleDebug
adb install -r -d app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.visionhelper/.MainActivity
```

在头显里从 **应用库 → 未知来源** 也能再次启动。

## 3. 戴上以后能看到什么

App 以 **2D 相框（Panel）** 形式运行 —— 这是普通 Android APK 在 HorizonOS 上的标准形态，
左右两侧分别是「识别画面」和「语音对话框」。

| 区域 | 按钮 | 说明 |
|---|---|---|
| 左·上排 | 输入源 / 识别一帧 / 连续识别 | 切换画面来源；对当前帧跑 YOLOv8n 检测并加框打标签 |
| 左·下排 | 截图入档 / 相册选图 / 记录库 | 把"带标注的画面"存进记录库；从相册挑图识别；查看/导出记录 |
| 右上 | 设备诊断 / 设置 | 诊断页查相机与麦克风能力；设置页填 LLM 的 API Key |
| 右·输入 | 输入框 / 发送 / 🎤 说话 | 文字提问或语音提问 |
| 右·下排 | 停止播报 / 清空 | 打断语音播报；清空对话 |

**启动后会自动跑一次识别**，所以一打开就能看到演示图上的彩色框与中文标签
（人 / 公交车 …），不需要任何相机权限。

**语音协议（产品需求核心）**：提问后 →
`思考中` → **回复文字先出现在气泡里** → 约 0.7 秒后才开始语音播报 → 可随时「停止播报」打断。

## 4. 关于 AI 对话

- **不填 Key 也能用**：走本地规则应答，用来完整体验"文字先行 + 语音播报"的交互链路
- **填 Key 就是真对话**：`设置 → API Key / Base URL / 模型`，任何 **OpenAI 兼容**服务都行

| 服务 | Base URL | 模型示例 |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 通义千问（兼容模式） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 本地 Ollama | `http://<你的电脑IP>:11434/v1` | `qwen2.5:7b` |

对话时会把**当前识别结果**作为上下文带给模型（例如"人3个、公交车1个"），
所以可以直接问"画面里有什么"。

## 5. 已知限制（务必先知道）

| 限制 | 原因 | 当前应对 |
|---|---|---|
| **拿不到头显"你看到的画面"** | HorizonOS 不向第三方 APK 开放透视原始帧 | 演示图 / 相册选图 / Camera2（需 Meta 签名的 `HEADSET_CAMERA`）三种输入源 |
| 相机源在 Quest 上大概率为空 | 同上，`HEADSET_CAMERA` 是 Meta 私有权限 | 演示图源保证功能可体验；诊断页会明确显示"无可用相机" |
| 中文语音播报可能没声音 | Quest ROM 未必带中文 TTS 引擎 | 协议强制"文字先行"，文字一定能看到；诊断页/状态栏会显示 TTS 引擎状态 |
| 系统语音识别需联网 | 系统 `SpeechRecognizer` 依赖 Google 服务 | 提供文字输入兜底；Phase 2 换 sherpa-onnx 离线 ASR |
| 录屏尚未接入 | 需真机验证 `MediaProjection` 在 HorizonOS 的可用性 | 已在诊断页预留验证路径 |

## 6. 排查

```bash
adb logcat -s VisionHelper:V AndroidRuntime:E     # 崩溃与 App 日志
adb shell dumpsys package com.visionhelper | head -30
adb uninstall com.visionhelper                     # 需要时卸载
```

App 界面底部始终显示 4 行滚动日志（模型载入耗时、识别耗时与数量、权限结果、语音识别错误等），
在头显里就能直接读，不必连电脑。
